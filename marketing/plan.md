# 30-day growth plan (2026-10-22 → 2026-11-22)

Order matters: fix the leaks first so every new visitor is worth more, then turn up traffic.

## Phase 1 — Fix the funnel (week 1, product work, James)

Each item is small and directly targets a measured leak.

| # | Change | Leak it targets | Expected effect |
|---|---|---|---|
| 1 | **"Quick Play" button** above the fold — starts the *Everything* channel instantly as "Guest" | 77% of visitors never start | Start rate 23% → 40%+ |
| 2 | Alias optional (default "Guest", rename at results screen) | Name box is friction before first play | Part of #1 |
| 3 | **Challenge prompt on results screen**: "Think your sister knows 70s hits better? Send her this round." | Only ~12% of players send a challenge; 97% of challenges get opened | Challenges 2× |
| 4 | **Daily Mystery Track** — one shared daily round + shareable score grid | ~1 game per player, no reason to return | Games/player ↑, daily post content |
| 5 | Replace placeholder testimonials with real stats: "268 players and counting · 85% finish every round · No app. No sign-up. Free." | FTC fake-review rule risk; press credibility | Compliance + trust |
| 6 | Feedback line on results screen ("Enjoyed it? One sentence") + permission-to-quote checkbox | No real testimonials | 3 real quotes in 2–4 weeks |
| 7 | Fix funnel widget: "Sent Challenge"/"Challenge Opened" show 0% while tiles show 32/31 | Can't trust funnel | Reliable weekly read |

## Phase 2 — Consistent free distribution (weeks 1–4)

**One channel, done well:** a Facebook Page + posting into relevant Facebook groups. The core
audience (55+, decade nostalgia, game-night hosts) is most active there. Add a second platform only
after 3 posts/week has held for a month.

Weekly rhythm (drafted by Claude in the Monday pack, approved by James in ~15 min):
- **Mon** — "Name that year" teaser (one clue, link to play)
- **Wed** — Channel spotlight (rotate all 14; 80s Hits is the current hot channel)
- **Fri** — Weekend challenge: "Beat my score on 70s Hits" with a challenge link
- **Daily (once #4 ships)** — Daily Mystery Track result grid

Plus 1–2 group posts/week in communities that allow it (read each group's rules first).

## Phase 3 — Pitch pipeline (5 targets/week)

Segments, in priority order — see `outreach-targets.md`:
1. 55+/retirement community newsletters & activity directors (proven fit; existing drafts)
2. Bars, breweries & venues running trivia/game nights (pass-the-phone + QR flyer; future revenue path)
3. Genre communities newly in scope: Latin, old-school hip-hop, reggae, country fan groups
4. Local press & radio "local-interest" desks

## Phase 4 — Revenue (only after players are climbing 4 weeks running)

Candidates to test, cheapest first: venue "Game Night Kit" (branded QR flyers + hosted room),
local sponsor per channel, senior-community activity licensing. Not before Phase 1–3 metrics move.
